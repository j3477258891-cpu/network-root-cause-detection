## 核心证据（为什么失败）

1. **训练集 5 折 OOF 中，全数据集只有 11 个订单存在"净增益 +1"的替换候选**（需要 45 个）。
   模拟基线（V11 冠军 3103 预算）命中率太高：候选对中 69% 的 remove 是真实 TP，
   可改进空间被压缩到极限。

2. **标签结构**（226 个训练候选对）：
   - 净增益 +1：30 对（13%）
   - 无效 0：111 对（49%）
   - 退化 -1：85 对（38%）← 比正例多 3 倍

3. **所有简单规则（residual 排序、语义分数差、rank 排序）的 top-45 精度均 ≈9%，
   期望净增益为负（-11 到 -18 TP）**。唯一有区分度的特征 count_residual
   （净增益候选 0.67 vs 退化候选 1.75）也不足以逆转类别不平衡。

4. **测试侧可替换空间核查**：
   - risk_keys（V117-V121 线上实验否定的基线节点）：47 个，涉及 43 订单
   - 但 V120 全部候选 conservative_p_net_gain ≥0.72 的为 **0 个**
   - 方程系统下 safe positive = 0

5. **与数学结论一致**：若 45 个候选真实成功率仅 0.50-0.55（当前证据乐观上界），
   P(F1≥0.945) = 30%-56%，远低于 80% 门槛。

## 解释

基线的可改进空间由全局数量决定：线上 P=1035、TP=956、FP=79、FN=88、G=1044。
79 个 FP 中真正"可删且能换成正确节点"的订单，在训练集同构模拟下只有 ~11 个。
这与 V41（71 候选仅 66% 正确）和 V120（19 合格、期望 +7 TP）的失败一致：
**不是模型能力问题，而是赛题当前基线的可替换订单数量不足 45 个高质量候选。**
