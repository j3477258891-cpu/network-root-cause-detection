用三模型堆叠分数（template_extra + template_hist + site_extra）在测试集分 3 片，

## 双轨探针（27 次配额，每天 ≤2 次）

### 轨道 A：分片重排（主，3 次提交）
| 探针 | 内容 | 片内 P | 变动规模 | 反推 |
|---|---|---|---|---|
| R1 | 片1 重排（182 单） | 315 | 8删8加（11单） | ΔTP_R1 |
| R2 | 片2 重排（182 单） | 357 | 16删16加（15单） | ΔTP_R2 |
| R3 | 片3 重排（182 单） | 363 | 9删9加（11单） | ΔTP_R3 |

- 每片提交 = 基线 + 该片重排，整体 P=1035、546 单、每单 ≤8
- 线上 F1 → TP 反推（TP=round(F1·2079/2)）→ ΔTP_片 = TP − 956
- **决策**：ΔTP_片 > 0 → 最终文件保留该片重排；ΔTP_片 ≤ 0 → 回退该片
- 目标：累计 ΔTP ≥ 27 → F1 ≥ 0.945
- OOF 校准期望：迁移率 70% → +28；60% → +24；50% → +20

### 轨道 B：动作探针（补充，8 次提交）
| 批次 | 内容 | 动作数 |
|---|---|---|
| P1-P3 | L1（score_margin>0 的 top 动作） | 4+4+2 |

- 每批 = 基线 + N 个同订单一删一加动作，P=1035
- 反推：正确动作数 k = (ΔTP + N)/2；每动作独立（订单去重）
- 用途：当分片重排被部分否定时，用已证实的正确动作补齐缺口

### 决策流程
1. 提交 R1/R2/R3（2 天内，每天 ≤2 次）
2. 若累计 ΔTP ≥ 27 → 直接发 final_map.csv（= 基线 + 正增益片重排）
3. 若累计 ΔTP ∈ [10, 27) → 用轨道 B 动作探针补齐（优先正 margin 动作）
4. 若累计 ΔTP < 10 或连续 3 批净 TP ≤ 0 → **止损，保留基线 0.919673**
